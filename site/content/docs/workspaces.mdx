## Two kinds

| Kind | Created by | Contents |
| --- | --- | --- |
| Scratch | `desk new` | An empty directory |
| Repository | `desk new REPOSITORY` | A Git clone |

Both use the same commands afterwards. `desk list` groups repository workspaces by canonical source, such as `github.com/octocat/hello-world`, and scratch workspaces under `playgrounds`.

## Names

Every new workspace gets a random two-word name, such as `drifting-tundra` or `misty-ember`. No task name is required. When a useful name emerges, run `desk rename local-test` for the current workspace, or `desk rename misty local-test` for another one.

Commands accept a unique prefix: `desk switch dri` works as long as no other workspace starts with `dri`. Leave the name out entirely and desk uses the workspace containing your current directory, even from deep inside it.

## Where workspaces live

```text
~/.desk/workspaces/
├── drifting-tundra/
└── misty-ember/          # a clone, with its own .git
```

These are plain directories. A repository workspace's source is its Git `origin`; activity and lifecycle metadata live outside project files in `~/.desk/state/`. Reuse preferences live in `~/.desk/preferences.json`. Use desk's commands to keep that state consistent. See [Configuration](/docs/configuration/) to use a different data root.

## Lifetime

[`desk finish`](/commands/finish/) marks work disposable; [`desk cleanup`](/commands/cleanup/) removes eligible inactive workspaces; [`desk rm`](/commands/rm/) removes one explicitly after confirmation. See [cleanup and retention](/docs/cleanup/) for the safety checks and 72-hour garbage window.
