## Two Kinds

| Kind | Created by | Contents |
| --- | --- | --- |
| Scratch | `desk new` | An empty directory |
| Repository | `desk new REPOSITORY` | A Git clone |

Both use the same commands afterwards. `desk list` shows a repository's origin and `scratch` for everything else.

## Names

Every workspace gets a random two-word name, an adjective and a noun, such as `drifting-tundra` or `misty-ember`. The name is the directory name, so there's nothing else to remember.

Commands accept a unique prefix: `desk cd dri` works as long as no other workspace starts with `dri`. Leave the name out entirely and desk uses the workspace containing your current directory, even from deep inside it.

## Where Workspaces Live

```text
~/.desk/workspaces/
├── drifting-tundra/
└── misty-ember/          # a clone, with its own .git
```

That's all. There is no registry: desk reads the directory each time it runs, and a repository workspace's source is its Git `origin`. You can rename, move, or delete workspace directories by hand. See [Configuration](/docs/configuration/) to use a different location.

## Lifetime

A workspace stays until you run [`desk rm`](/commands/rm/) or delete it yourself. desk never deletes anything on its own, and runs nothing in the background.
