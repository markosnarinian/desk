---
title: Clear away finished work
description: Preview inactive workspaces safely, or remove one explicitly.
---

## Review what you've kept

```sh
desk list
desk cleanup
```

Cleanup previews **managed workspaces inactive for at least 72 hours**, then asks before removing all candidates. `desk cleanup --yes` skips only confirmation, not safety checks. It does not scan arbitrary project directories.

Directories without state remain outside cleanup until you explicitly enter them through `desk switch`, select them with `desk new`, or mark them finished. Listing alone does not start managed state.

## Mark a scratch workspace disposable

```sh
desk finish                # current workspace
desk finish misty          # another workspace by name or unique prefix
```

Scratch workspaces without a remote need this signal before cleanup can consider them. Finishing never removes files immediately or bypasses inactivity, running-process, or Git safety checks. You can also finish a repository workspace.

## What protects a repository

Cleanup excludes:

- untracked, uncommitted, or ignored files, including in nested repositories;
- stashes and unpushed commits, including other branches, tags, and detached HEAD;
- Git inspection failures;
- detectable running processes and live Amp follow sessions.

Even ignored files such as `.env` can be important. Review them yourself and use explicit `desk rm` if you want to discard them.

Checks use locally known remote-tracking refs without fetching. They cannot guarantee the remote server still holds your work; cleanup is not a backup.

## What counts as activity

desk tracks saved file/directory changes, recorded `new`/`switch` visits, and detectable processes—not every editor keystroke or unsaved buffer. A quiet editor is not a reliable activity signal.

## Remove one explicitly

```sh
desk rm misty
```

Explicit removal shows a summary and asks before moving **whatever you confirm, including local-only work**. With shell integration, removing your current workspace takes you home.

## Garbage is temporary, not a backup

Both removal commands move workspaces to `~/.desk/garbage` (or `$DESK_HOME/garbage`) for **72 hours from removal**. This is separate from the 72-hour inactivity requirement before cleanup.

Every desk invocation silently collects expired garbage; there is no daemon. Once retention expires, the next invocation may permanently delete it. Never keep your only copy of important work there.
