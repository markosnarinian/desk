## What is desk?

Most local work is planned: your main projects live where you put them. The rest is not. You try a library in an empty folder, clone a repository to check one thing, fix a typo in a project you do not usually work on. Those directories pile up, and after a few weeks you no longer know which ones are safe to delete.

**desk** gives that in-between work a home. Every experiment or clone gets its own workspace in a private directory that desk manages. You work in it with your normal shell and tools, leave when you are done, and decide later, explicitly, what to clean up.

## What desk Is Not

desk manages **directories**, not development environments. It does not install toolchains, run containers, or sync anything. It also deliberately leaves out:

- automatic or age-based cleanup, and anything that runs in the background;
- `git pull` or resets when you reopen a repository;
- Git worktrees and shell functions;
- Windows support.

<Callout type="info">
desk is in its initial release. It runs on macOS and Linux, and it is installed by building from source.
</Callout>
