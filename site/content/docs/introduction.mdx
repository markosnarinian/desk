## What is desk?

Most local work is planned: your main projects live where you put them. The rest is not. You try a library in an empty folder, clone a repository to check one thing, fix a typo in a project you do not usually work on. Those directories pile up as `test-2`, `tmp-fix`, and a third clone of the same repo.

**desk** gives that in-between work a home. `desk new` creates a workspace with a memorable name such as `misty-ember` and takes you there. Your prompt shows which workspace you're in, `desk cd` jumps between them, and `desk rm` deletes one when you're done.

## What desk Is Not

desk manages **directories**, not development environments. It does not install toolchains, run containers, or sync anything. It also deliberately leaves out, for now:

- automatic cleanup, and anything that runs in the background;
- `git pull` or resets when you return to a repository;
- editor and Amp integrations;
- Windows support.

<Callout type="info">
desk is early and deliberately minimal. It runs on macOS and Linux, and it is installed by building from source.
</Callout>
