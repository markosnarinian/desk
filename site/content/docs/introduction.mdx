As agents move more programming work to the cloud, local work becomes occasional and fragmented: temporary repository clones, playgrounds, exploration, experiments, throwaway scaffolding, and local prototypes.

desk makes those workspaces easy to create, return to, and retire. Use your usual tools locally, or [bring Amp orb work home](/docs/amp/) to edit a snapshot or test live changes without pushing first.

## A short session

With desk's shell integration and Node.js installed:

```text title="Terminal"
$ desk new
desk: created misty-ember
(misty-ember) $ printf 'console.log(2 ** 10)\n' > try.js
(misty-ember) $ node try.js
1024
(misty-ember) $ desk rm
Delete misty-ember (has files)? [y/N] y
Moved to garbage for 72 hours.
```

Names are generated; no task name is needed. `desk new owner/repo` starts from a Git clone instead. `desk list` shows what you've kept; `desk switch NAME` takes you back.

## Start here

[Install desk](/docs/installation/), then follow the [Quickstart](/docs/quickstart/). Browse [Commands](/commands/overview/) for syntax and flags.

desk runs on macOS and Linux, with zsh (including Oh My Zsh), bash, and fish integration. Workspaces are plain directories, not containers or VMs: dependencies, services, and secrets remain yours to set up.

[Cleanup](/docs/cleanup/) is explicit and checks for local-only work. Removed workspaces stay in garbage for 72 hours before a later desk invocation permanently deletes them. There is no daemon. Licensed under GNU AGPL v3.
