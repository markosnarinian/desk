## No Configuration File

desk has no configuration file and no background process. `~/.config/desk/` is reserved for future configuration; desk does not create or read it today.

## Environment Variables

<ParamField name="DESK_HOME" type="absolute path" default="~/.desk">
Overrides the data root. Workspaces live in its `workspaces/` directory. Must be an absolute path. Changing it does not move existing workspaces.
</ParamField>
<ParamField name="DESK_PROMPT_DISABLE" type="any value">
Stops [shell integration](/docs/shell-integration/) from changing your prompt.
</ParamField>

Don't keep work you want to return to in OS-managed temporary storage such as `/tmp`.

## Git

desk runs your installed `git` with your normal configuration, credentials, and SSH setup. It ignores inherited `GIT_DIR`, `GIT_WORK_TREE`, and `GIT_INDEX_FILE`, so running it from a Git hook can't point it at a different repository.

## Earlier Versions

Earlier versions kept a registry, locks, and quarantine in the data root and named workspaces with 12-character IDs. desk now ignores the registry, locks, and quarantine directory. Old workspaces still appear in `desk list` under their IDs; rename or delete them like any other directory.

Platform-specific roots from before `~/.desk` became the default (`~/.local/share/desk` on Linux, `~/Library/Application Support/desk` on macOS) are not read. Set `DESK_HOME` to an old root, or move its `workspaces/` directory into `~/.desk`.
