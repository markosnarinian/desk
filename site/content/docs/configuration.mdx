## Data root

desk stores data under `~/.desk`, outside project files:

| Path | Contents |
| --- | --- |
| `workspaces/` | Scratch directories and independent Git clones |
| `state/NAME.json` | Activity and lifecycle metadata |
| `preferences.json` | Per-repository reuse preferences set by `desk new --reuse` |
| `garbage/` | Removed workspaces, retained for 72 hours |

Use desk commands to keep metadata consistent. There is no daemon; every invocation collects expired garbage. Avoid OS-managed temporary storage such as `/tmp` for work you want to return to.

## Environment variables

| Variable | Effect |
| --- | --- |
| `DESK_HOME` | Override the entire data root. Must be an absolute path; changing it does not move existing data. |
| `DESK_PROMPT_DISABLE` | Set before loading shell integration to disable the workspace prompt prefix. |

## Git

desk uses your installed Git with your normal configuration, credentials, and SSH setup. It ignores inherited `GIT_DIR`, `GIT_WORK_TREE`, and `GIT_INDEX_FILE`, so Git hooks can't redirect its repository operations.

## Pre-release data

Old workspace directories remain usable, including those with 12-character IDs; `desk rename` can give them readable names. Directories without state remain outside cleanup until explicitly used through `switch`, selected with `new`, or marked with `finish`.

Older platform-specific roots (`~/.local/share/desk` on Linux and `~/Library/Application Support/desk` on macOS) are not read automatically. Set `DESK_HOME` to the old root or move its `workspaces/` directory into `~/.desk`. Old registry, lock, and quarantine files are not used.
