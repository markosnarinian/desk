title: Shell integration
description: Automatic setup for zsh (including Oh My Zsh), bash, and fish.
---

## Set up once

```sh
desk init
```

desk detects your shell from `$SHELL`, updates its startup configuration, and tells you what changed. Open a new terminal to load it. Running init again is safe; it doesn't add duplicate setup.

To choose explicitly:

```sh
desk init zsh
desk init bash
desk init fish
```

Use the command for your shell, not all three. A child process cannot change the shell you're already using.

For bash, setup covers both `.bashrc` and the active login file (`.bash_profile`, `.bash_login`, or `.profile`). Fish uses `$XDG_CONFIG_HOME/fish/config.fish`, or `~/.config/fish/config.fish`.

## Oh My Zsh

Zsh setup detects Oh My Zsh from `$ZSH` or the `oh-my-zsh.sh` source line in your startup file. It uses the same zsh integration, loaded through a custom plugin after your existing setup. Your plugin list, custom directory, and theme stay unchanged. Use `desk init oh-my-zsh` only if detection misses your setup; it adds no extra features.

The plugin is installed under exported `$ZSH_CUSTOM`, or `$ZSH/custom`, with `~/.oh-my-zsh/custom` as the default. Export a custom location before running init to install there. Zsh startup configuration follows `$ZDOTDIR` when set.

## What changes

- `desk new` and `desk switch` move into a workspace.
- The prompt shows the workspace and your path inside it: `(misty-ember/src/api)`.
- Tab completes commands and workspace names.
- `desk rm` takes you home if you delete the workspace you're in.

Outside a workspace, your prompt stays unchanged. The prefix works with Oh My Zsh themes and fish's default prompt.

## Manual or temporary loading

`--print` outputs integration without editing any files:

<Tabs>
<Tab title="zsh">

```sh
eval "$(desk init zsh --print)"
```

</Tab>
<Tab title="bash">

```sh
eval "$(desk init bash --print)"
```

</Tab>
<Tab title="fish">

```sh
desk init fish --print | source
```

</Tab>
</Tabs>

Upgrading? Run `desk init` once. It replaces the old standalone eval or fish source lines with managed setup. For custom conditional, multiline, or separately sourced loaders, add `--print` yourself. Plain `desk init` now installs setup instead of printing it.

## Custom prompts

Set `DESK_PROMPT_DISABLE=1` before loading integration to turn off the prefix. `desk_prompt_info` prints the workspace and relative path, or nothing outside a workspace. Use it from your own prompt function or theme.

Without integration, use `cd "$(desk info NAME --path)"` to enter a workspace.
