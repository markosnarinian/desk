## Requirements

- **macOS or Linux**, on amd64 or arm64.
- **Go 1.24 or newer**, to build the binary. desk has no Go dependencies outside the standard library.
- **Git**, to use repository workspaces. Scratch workspaces do not need it.
- **Installed, authenticated Amp CLI**, only for `desk amp`.

desk is a single executable. It needs no daemon or manual configuration, and Go is not needed after the build. It stores workspace metadata and reuse preferences in its [data root](/docs/configuration/), outside project files.

desk is licensed under GNU AGPL v3. These steps require source access; no public binary releases have been published yet.

## Build from Source

<Steps>
<Step title="Get the source">
Clone the repository and change into it.

```sh
git clone https://github.com/markosnarinian/desk.git
cd desk
```
</Step>
<Step title="Build the binary">
Build into a directory on your PATH. This example uses `~/.local/bin`.

```sh
mkdir -p "$HOME/.local/bin"
go -C cli build -trimpath -o "$HOME/.local/bin/desk" .
```
</Step>
<Step title="Set up your shell">
Run the binary directly; you don't need to edit PATH or a startup file yourself.

```sh
"$HOME/.local/bin/desk" init
```

desk detects zsh (including Oh My Zsh), bash, or fish and installs shell integration. To choose explicitly, use `init zsh`, `init bash`, or `init fish`.
</Step>
<Step title="Verify">
Open a new terminal and check that desk runs.

```sh
desk version
```

A source build prints `dev`. Continue to the [Quickstart](/docs/quickstart/) for a first experiment, or [Shell integration](/docs/shell-integration/) for custom setup.
</Step>
</Steps>

## Release Archives

The repository includes a script that builds archives for macOS and Linux on amd64 and arm64, plus a `SHA256SUMS` file:

```sh
scripts/release.sh v0.1.0
```

Each archive contains the `desk` binary and `LICENSE`. Check the archive against `SHA256SUMS` before extracting it. These binaries are not signed or notarized, and no public releases have been published yet, so building from source is the supported way to install.

## Uninstall

Remove desk-managed blocks from your shell startup files, then delete the binary. For Oh My Zsh, also remove the managed block in `plugins/desk/desk.plugin.zsh` and any manually added `desk` plugin entry. Delete the plugin file if nothing else remains. Your workspaces stay in `~/.desk/workspaces/` until you delete them.

```sh
rm "$HOME/.local/bin/desk"
```
