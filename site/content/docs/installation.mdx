title: Installation
description: Build desk from source and put it on your PATH on macOS or Linux.
---

## Requirements

- **macOS or Linux**, on amd64 or arm64.
- **Go 1.23 or newer**, to build the binary. desk has no Go dependencies outside the standard library.
- **Git**, to use repository workspaces. Scratch workspaces do not need it.

desk is a single executable. It needs no daemon, shell function, or configuration file, and Go is not needed after the build.

## Build from Source

<Steps>
<Step title="Get the source">
Clone the repository and change into it.

```sh
git clone https://github.com/markosnarinian/desk.git
cd desk
```
</Step>
<Step title="Build the binary">
Build into a directory on your PATH. This example uses `~/.local/bin`.

```sh
mkdir -p "$HOME/.local/bin"
(cd cli && go build -trimpath -o "$HOME/.local/bin/desk" .)
```
</Step>
<Step title="Add it to your PATH">
Skip this step if `~/.local/bin` is already on your PATH.

<Tabs>
<Tab title="zsh">

```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
```

</Tab>
<Tab title="bash">

```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```

</Tab>
</Tabs>
</Step>
<Step title="Verify">
Open a new shell and check that desk runs.

```sh
desk version
```

A source build prints `dev`. Run `desk help` to see every command.
</Step>
</Steps>

<Callout type="warning">
Never run desk with `sudo`. Its data root is private to your user.
</Callout>

## Release Archives

The repository includes a script that builds archives for macOS and Linux on amd64 and arm64, plus a `SHA256SUMS` file:

```sh
scripts/release.sh v0.1.0
```

Each archive contains the `desk` binary and `SAFETY.md`. Check the archive against `SHA256SUMS` before extracting it. These binaries are not signed or notarized, and none have been published yet, so building from source is the supported way to install.

## Uninstall

Delete the binary. Your workspaces stay where they are. Use `desk list` first if you want to move anything out of them; see [Configuration](/docs/configuration/) for where they live.

```sh
rm "$HOME/.local/bin/desk"
```
