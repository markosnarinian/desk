---
title: Quickstart
description: Create a workspace, return to it, and clear it away.
---

[Install desk](/docs/installation/), run `desk init`, and open a new terminal.

## Start an experiment

```sh
desk new
```

Your shell enters an empty directory; the prompt shows its generated name, such as `(misty-ember)`. Use your usual tools to try a library, scaffold a project, or build a prototype.

For a repository instead:

```sh
desk new octocat/Hello-World
```

desk offers existing workspaces for that repository or a new independent clone. It never pulls or resets an existing clone. See [repository workspaces](/docs/repository-workspaces/) for reuse options.

## Return later

```sh
desk list                  # find the generated name
desk switch misty          # name or unique prefix
desk info                  # name, path, and source
desk rename local-test     # optional: give it a useful name
```

From a subdirectory, `desk switch` without a name returns to the workspace root.

## Finish

```sh
desk finish                # mark the current workspace disposable
desk cleanup               # preview eligible workspaces, then confirm
```

Cleanup considers managed workspaces inactive for at least 72 hours, excluding local-only work and detectable running processes. Scratch workspaces without a remote require `finish` first; it never bypasses Git safety checks.

Need it gone now? `desk rm [NAME]` asks before removing even local-only work. Both removal commands retain garbage for 72 hours, then any desk invocation may permanently delete it. See [cleanup and retention](/docs/cleanup/).

To test an agent's work, use `desk amp`: choose **copy** for an editable snapshot or **follow** for live updates. Read [Test Amp work locally](/docs/amp/) before following; stopping restores the pre-sync checkout.
