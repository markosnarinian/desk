---
title: Quickstart
description: Create a workspace, move between workspaces, and delete one when you're done.
---

First [install desk](/docs/installation/) and add [shell integration](/docs/shell-integration/), which lets `desk` change your directory and show where you are.

<Steps>
<Step title="Start something">
```sh
desk new
```

```text
desk: created drifting-tundra
```

You're now in an empty directory, and your prompt starts with `(drifting-tundra)`.
</Step>
<Step title="Work on a repository">
```sh
desk new octocat/Hello-World
```

desk clones the repository into a new workspace, such as `misty-ember`, and takes you there. Running the same command later takes you back to that clone instead of cloning again.
</Step>
<Step title="Move around">
```sh
desk list          # * marks the workspace you're in
desk cd drift      # a unique prefix is enough
mkdir -p src/api && cd src/api
desk cd            # back to the top of drifting-tundra
```

While you're in `src/api`, your prompt shows `(drifting-tundra/src/api)`.
</Step>
<Step title="Finish">
```sh
desk rm
```

```text
Delete drifting-tundra (has files)? [y/N] y
desk: deleted drifting-tundra
```

`rm` deletes the workspace you're in, or the one you name, after you confirm. Nothing is ever deleted automatically.
</Step>
</Steps>
