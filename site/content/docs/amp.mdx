---
title: Test Amp work locally
description: Copy an Amp task to edit locally, or follow live changes in a fresh clone without pushing.
---

## Choose a task

Install Git and the Amp CLI, and sign in to Amp first. Then run:

```sh
desk amp
```

Browse recent tasks, or paste a thread URL or ID directly:

```sh
desk amp THREAD
```

desk asks whether to **copy** or **follow** when you omit a mode. It creates a fresh independent clone using the thread's repository metadata. If that metadata is missing or insufficient, supply a repository explicitly:

```sh
desk amp THREAD --copy \
  --repository owner/repo
```

`THREAD` stands for your actual URL or thread ID, not a workspace name. See the [command reference](/commands/amp/).

## Keep a copy to edit

```sh
desk amp THREAD --copy
```

Copy delegates to `amp sync --apply` to bring the task's code into the fresh workspace. It includes uncommitted and unpushed work; you don't need to commit or push in the orb first. The snapshot stays locally for you to inspect, run, and edit with your usual tools.

## Follow while the agent works

```sh
desk amp THREAD --follow
```

Follow delegates to Amp's live sync and stays in the foreground. Leave that terminal running. In a **separate terminal**, find the new workspace and enter it:

```sh
desk list
desk switch NAME
```

Replace `NAME` with the generated workspace name. Run the project's setup and tests there as updates arrive.

<Callout type="warning">
Don't edit locally while following: live updates own the checkout. Stop follow in its original terminal when you're done. Stopping restores the pre-sync checkout, not an editable copy of the latest synced work. Use copy mode if you want to keep and change the task's files.
</Callout>

## Set up the project locally

This transfers code, not an environment. Dependencies, running services, toolchains, and secrets are not replicated. Install and configure what the project requires before testing. Your installed Git handles clone authentication with your usual credentials.

Live follow prevents [cleanup](/docs/cleanup/). When a workspace is no longer useful, mark it with `desk finish` or remove it explicitly with `desk rm` after reviewing its contents.
