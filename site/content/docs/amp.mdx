---
title: Test Amp work locally
description: Copy an orb's work to edit locally, or follow live changes without pushing.
---

Requires Git and an installed, authenticated [Amp CLI](https://ampcode.com). Run `desk amp` to browse recent tasks, or pass a thread URL or ID:

```sh
desk amp THREAD --copy      # keep an editable snapshot
desk amp THREAD --follow    # watch live changes in the foreground
```

Omit the mode to choose interactively. Both modes create a fresh independent clone and include uncommitted and unpushed code. If the thread's repository metadata is missing or insufficient, add `--repository owner/repo`.

## Copy to edit

Copy uses `amp sync --apply`. The snapshot stays in the local workspace for you to inspect, run, and change with your usual tools.

## Follow to test

Leave follow running. In a **separate terminal**, find and enter the new workspace:

```sh
desk list
desk switch NAME
```

Run the project's setup and tests as updates arrive. Live follow prevents cleanup.

<Callout type="warning">
Don't edit locally while following: live updates own the checkout. Stopping follow restores the pre-sync checkout, not the latest synced files. Use copy mode to keep work you want to edit.
</Callout>

## Code, not an environment

Dependencies, services, toolchains, and secrets are not replicated. Run the project's usual setup locally. Cloning uses your normal Git credentials.

When finished, use `desk finish` or explicitly remove the workspace with `desk rm`. See the [command reference](/commands/amp/) and [cleanup](/docs/cleanup/).
