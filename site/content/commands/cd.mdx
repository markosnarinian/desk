---
title: desk cd
description: Go to a workspace by name or prefix, or to the top of the current one.
---

## Usage

```text title="Usage"
desk cd [NAME]
```

## Arguments

<ParamField name="NAME" type="optional">
A workspace name or a unique prefix of one. Leave it out to go to the top directory of the workspace you're in.
</ParamField>

## Behavior

`desk cd` is a shell function from [shell integration](/docs/shell-integration/): a program cannot change its parent shell's directory. It runs `desk path` and changes to the result. Without shell integration, desk prints an error explaining how to set it up, or use:

```sh
cd "$(desk path NAME)"
```

## Examples

```sh
desk cd mis                # misty-ember, if it's the only match
cd src/api
desk cd                    # back to the top of misty-ember
```

An ambiguous prefix lists the candidates and leaves you where you are:

```text
desk: "misty" matches misty-ember, misty-river
```
