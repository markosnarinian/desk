---
title: desk done
description: Mark a workspace as finished so that desk gc considers it for cleanup.
---

## Usage

```text title="Usage"
desk done ID
```

## Arguments

<ParamField name="ID" type="workspace ID" required>
The workspace you are finished with.
</ParamField>

## Behavior

Sets the workspace's state to `done`. Nothing is moved or deleted, and any running session continues.

`desk gc --apply` only quarantines workspaces in this state. To quarantine a single workspace without marking it first, use [`desk remove`](/commands/remove/).

The flag is cleared again when you `desk enter` or `desk restore` the workspace.

## Errors

| Message | Cause |
| --- | --- |
| `workspace is pinned; use keep ID --off first` | Pinned workspaces cannot be marked done. |
| `already quarantined` | The workspace is in quarantine. |

## Example

```sh
desk done 7e4a9b23c810
desk gc
```
