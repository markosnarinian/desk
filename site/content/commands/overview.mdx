## Usage

```text title="Usage"
desk COMMAND [ARGUMENT]
```

| Command | Purpose |
| --- | --- |
| [`desk new [REPOSITORY] [--fresh\|--choose\|--reuse]`](/commands/new/) | Start scratch work, choose a workspace, or make an independent clone |
| [`desk switch [NAME]`](/commands/switch/) | Go to a workspace |
| [`desk info [NAME] [--path]`](/commands/info/) | Show a workspace's name, path, and source |
| [`desk list`](/commands/list/) | Show a tree grouped by source repository, plus scratch |
| [`desk rename [NAME] NEW_NAME`](/commands/rename/) | Rename the current workspace or a named one |
| [`desk finish [NAME]`](/commands/finish/) | Mark a workspace disposable without removing it |
| [`desk cleanup [--yes]`](/commands/cleanup/) | Preview and remove eligible inactive workspaces |
| [`desk rm [NAME]`](/commands/rm/) | Move a workspace to garbage after confirmation |
| [`desk amp [THREAD] [--copy\|--follow] [--repository REPOSITORY]`](/commands/amp/) | Copy or follow an Amp task in a fresh clone |
| [`desk init [SHELL] [--print]`](/commands/init/) | Set up your shell, or print integration without installing |
| [`desk version`](/commands/version/) | Print the version |

`desk help`, `desk --help`, or `desk` with no arguments prints a summary.

## Conventions

<ParamField name="NAME" type="name or prefix">
A workspace name such as `misty-ember`, or any prefix that matches only one workspace, such as `mis`. Leave it out to use the workspace containing your current directory.
</ParamField>
<ParamField name="REPOSITORY" type="owner/repo, URL, or path">
GitHub `owner/repo`, any Git URL, or a local path that starts with `/`, `./`, or `../`.
</ParamField>

`desk new` and `desk switch` change your directory with [shell integration](/docs/shell-integration/). Run `desk init` once, then open a new terminal. Without it, `desk new` still creates the workspace and prints its path. `desk switch` only enters existing workspaces; it never creates a clone.

## Removal and retention

`cleanup` checks eligibility; `rm` removes whatever you confirm. Both retain garbage for 72 hours before any desk invocation can permanently delete it. Read [cleanup and retention](/docs/cleanup/) before discarding work.

## Output and exit status

Paths and listings go to standard output. Messages and prompts go to standard error, so `cd "$(desk new)"` works in scripts. Errors print with a `desk:` prefix and exit with status `1`:

```text
desk: no workspace "nope" (see desk list)
```
