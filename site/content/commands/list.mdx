---
title: desk list
description: Show every workspace and where it came from.
---

## Usage

```text title="Usage"
desk list
```

`list` takes no arguments.

## Output

```text
  drifting-tundra  scratch
* misty-ember      https://github.com/octocat/Hello-World.git
```

Each line shows a workspace name and its Git `origin`, or `scratch` for a workspace that is not a clone. `*` marks the workspace containing your current directory.

`list` reads only local files, so it is instant and works offline. With no workspaces, it prints a hint to standard error and nothing on standard output.
