---
title: desk list
description: Show a workspace tree grouped by source repository, plus scratch.
---

## Usage

```text title="Usage"
desk list
```

`list` takes no arguments.

## Output

```text
github.com/octocat/hello-world
├── * misty-ember  /home/you/.desk/workspaces/misty-ember
└──   quiet-forest  /home/you/.desk/workspaces/quiet-forest
playgrounds
└──   drifting-tundra  /home/you/.desk/workspaces/drifting-tundra
```

The tree groups workspaces by canonical source repository, with scratch workspaces under `playgrounds`. Each child shows its name and absolute path; `*` marks the workspace containing your current directory. Names in the example are generated. Use `desk info NAME` for one workspace, or `desk info NAME --path` for a path you can pass to another tool.

`list` works offline. With no workspaces, it prints a hint to standard error and nothing on standard output.
