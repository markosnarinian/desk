---
title: desk init
description: Set up zsh (including Oh My Zsh), bash, or fish automatically.
---

## Usage

```sh
desk init [SHELL] [--print]
```

`SHELL` is `zsh`, `bash`, or `fish`. Leave it out to detect your shell from `$SHELL`. Zsh setup includes automatic Oh My Zsh detection.

## Automatic setup

```sh
desk init
```

Updates your shell startup configuration to load directory switching, the workspace prompt, and completion. It preserves existing configuration and avoids duplicate setup. Open a new terminal afterward.

Only if Oh My Zsh detection misses your setup, force it with:

```sh
desk init oh-my-zsh
```

This uses the same zsh integration, not additional features. See [Shell integration](/docs/shell-integration/) for setup locations and detection.

## Print without installing

Use `--print` for manual setup or to load integration in the current shell:

```sh
eval "$(desk init zsh --print)"
```

For fish, use `desk init fish --print | source`. No startup files are changed in print mode.
