---
title: desk init
description: Print the shell integration script for zsh, bash, or fish.
---

## Usage

```text title="Usage"
desk init SHELL
```

## Arguments

<ParamField name="SHELL" type="zsh | bash | fish" required>
The shell to print integration for.
</ParamField>

## Behavior

Prints a script for your shell's startup file to load. It defines the `desk` shell function, which lets `desk new` and `desk cd` change your directory, adds the current workspace to your prompt, and completes commands and workspace names. See [Shell integration](/docs/shell-integration/).

## Examples

<Tabs>
<Tab title="zsh">

```sh
echo 'eval "$(desk init zsh)"' >> ~/.zshrc
```

</Tab>
<Tab title="bash">

```sh
echo 'eval "$(desk init bash)"' >> ~/.bashrc
```

</Tab>
<Tab title="fish">

```sh
echo 'desk init fish | source' >> ~/.config/fish/config.fish
```

</Tab>
</Tabs>
