---
title: desk version
description: Print the version of the desk binary.
---

## Usage

```text title="Usage"
desk version
```

`version` takes no arguments or flags.

## Output

Release builds print the version they were built with, such as `v0.1.0`. Builds made directly with `go build` print `dev`.

```sh
desk version
```

```text
dev
```

## Setting the Version

`scripts/release.sh` sets the version at build time with Go's linker flags:

```sh
go build -ldflags "-X main.version=v0.1.0" -o desk .
```
