---
title: desk gc
description: Preview cleanup of finished workspaces, or move the eligible ones to quarantine.
---

## Usage

```text title="Usage"
desk gc [--dry-run]
desk gc --apply --quiescent
```

## Flags

<ParamField name="--dry-run" type="flag" default="on">
Explain what would happen without changing anything. This is the default; the flag exists for clarity in scripts.
</ParamField>
<ParamField name="--apply" type="flag">
Quarantine every eligible workspace. Cannot be combined with `--dry-run`, and requires `--quiescent`.
</ParamField>
<ParamField name="--quiescent" type="flag">
Confirms that no shell, editor, server, or other process is using the workspaces that will move.
</ParamField>

## Behavior

`gc` goes through every workspace and prints one line for each. A workspace is eligible when it:

1. is not already quarantined,
2. is marked [done](/commands/done/), and
3. passes every [retention rule](/docs/retention-rules/).

With `--apply`, each eligible workspace is moved to quarantine immediately. Nothing is ever purged by `gc`.

## Output

<Tabs>
<Tab title="Dry run">

```sh
desk gc
```

```text
bb5ff6487d99 retained: not marked done
702378b08f9e would quarantine (requires --apply --quiescent)
bf22fab17609 retained: pinned
```

</Tab>
<Tab title="Apply">

```sh
desk gc --apply --quiescent
```

```text
bb5ff6487d99 retained: not marked done
702378b08f9e quarantined
bf22fab17609 retained: pinned
```

</Tab>
</Tabs>

<Callout type="info">
A run that reports retained workspaces still succeeds. Read each line rather than relying on the exit status.
</Callout>
