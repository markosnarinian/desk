title: desk scratch
description: Create an empty scratch workspace and start a shell in it.
---

## Usage

```text title="Usage"
desk scratch [NAME] [--no-enter]
```

## Arguments

<ParamField name="NAME" type="string" default="scratch">
A label for the workspace, shown in `desk list`. It does not need to be unique and does not affect the directory name.
</ParamField>

## Flags

<ParamField name="--no-enter" type="flag">
Create the workspace and print its ID without starting a shell.
</ParamField>

## Behavior

1. Generates a random 12-character ID.
2. Creates an empty, private directory for it under `workspaces/` in the data root.
3. Prints the ID on standard output.
4. Unless `--no-enter` is given, starts a [session](/docs/sessions/) in the new directory.

## Examples

<Tabs>
<Tab title="Interactive">

```sh
desk scratch experiment
```

```text
7e4a9b23c810
desk: entering experiment (7e4a9b23c810); exit to return; nothing is deleted
```

</Tab>
<Tab title="Scripted">

```sh
id=$(desk scratch build-test --no-enter)
echo "created $id"
```
