---
title: desk path
description: Print the absolute path of a workspace, for scripts and other tools.
---

## Usage

```text title="Usage"
desk path [NAME]
```

## Arguments

<ParamField name="NAME" type="optional">
A workspace name or a unique prefix of one. Leave it out to use the workspace containing the current directory.
</ParamField>

## Examples

```sh
desk path misty
```

```text
/home/you/.desk/workspaces/misty-ember
```

Open a workspace in another tool:

```sh
code "$(desk path misty)"
```

Outside a workspace, `desk path` with no NAME fails:

```text
desk: not inside a workspace; give a NAME (see desk list)
```
