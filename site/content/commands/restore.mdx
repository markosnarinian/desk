---
title: desk restore
description: Move a quarantined workspace back to managed storage.
---

## Usage

```text title="Usage"
desk restore ID
```

## Arguments

<ParamField name="ID" type="workspace ID" required>
A quarantined workspace.
</ParamField>

## Behavior

Moves the directory from `quarantine/` back to `workspaces/`, clears its done flag and quarantine timestamp, and keeps any pin. The workspace is `ready` and can be entered immediately.

No `--quiescent` is needed: restoring never removes data.

## Example

```sh
desk restore 702378b08f9e
```

```text
restored 702378b08f9e
```

## Errors

| Message | Cause |
| --- | --- |
| `workspace is not quarantined` | The workspace is already in managed storage. |
| `workspace directory missing; registry retained` | The directory was removed outside desk. |
